벨로키의 5단계 체크포인트

01

입력부터 정리

목적, 대상, 길이, 화면비, 파일 위치와 유지해야 할 문장을 적는다. 민감한 영상은 외부 전송 여부도 확인한다.

02

말과 시간을 맞춘다

기존 영상은 단어별 타임스탬프를 확인하고 고유명사와 잘린 단어를 고친다. 틀린 받아쓰기로 컷을 만들면 잘못된 지점이 증폭된다.

03

러프 컷 또는 스토리보드

무음 0.25초는 빠른 편집의 출발값일 뿐. 의미 있는 쉼은 남긴다. 새 영상은 훅 → 맥락 → 결과 → 브랜드 순서로 1장면 1메시지.

04

저렴하게 먼저 확인

기존 영상은 컷 경계를 들어보고, 새 영상은 대표 정지 화면을 확인한다. 틀린 메시지와 브랜드 색부터 수정한다.

05

자동 검사 후 사람 귀와 눈

lint → check → render. 출력 파일을 처음부터 끝까지 보고, 소리만 따로 들어 대사·음악·컷을 확인한다.

기존 영상 러프 컷
